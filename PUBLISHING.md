# Publishing VoiceMeeter AEC

The Source archive is the repository content. Extract it and commit the files inside it, with README.md and Cargo.toml at the repository root. A suitable repository name is `voicemeeter-aec`.

`VoiceMeeter-AEC-Setup.exe` is the recommended Windows download. It performs a per-user installation without elevation, adds a Start menu shortcut and creates a standard uninstall entry. The Windows-x64 archive remains the portable package and the payload used by automatic updates. It contains the self-contained desktop app, the audio engine and grouped licence notices. The separate Source archive contains the corresponding source, installer definition and vendored Rust dependencies. Attach all three packages and their SHA-256 files to the GitHub release. Do not commit executable build outputs to the source repository.

Run Build.cmd on Windows x64 with Rust, Visual C++, Windows SDK and the .NET 8 SDK or newer installed. Install Inno Setup 7 before packaging, or provide its compiler path through `-InstallerCompiler` or `INNO_SETUP_COMPILER`. The build remaps local source paths out of the native engine, publishes a self-contained x64 desktop app, runs unit and synthetic audio checks for Gentle/Balanced, validates the bilingual interface, and renders the README screenshot without opening audio. Balanced is the app default for new setups. Strong remains optional, has documented near-end preservation failures and is not included in the passing quality gate.

Run `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Package.ps1` after a successful build. It creates the installer plus fresh Source and Windows-x64 archives under `dist`, with SHA-256 files. Packaging uses explicit file lists and never reads the user's saved application settings. Existing packages are not overwritten; use a new output directory when repackaging. Keep the generated `VoiceMeeter-AEC-{version}-Windows-x64.zip` name and attach its `.sha256` file to the same stable GitHub release: the in-app updater requires that pair. `-SkipInstaller` is available for local portable-only builds.

Keep the GPL license, third-party notices and dependency license files. Review VALIDATION-EN.md before describing the release: the automated engine and interface checks pass, while controlled room, real-speech, long-duration and hardware-latency measurements remain outstanding. The project is independent of VB-Audio and Steinberg.

The public package contains generic column examples and synthetic validation transcripts. Personal routing presets, Windows startup entries, local diagnostic logs, build outputs and repository metadata are excluded. The runtime saves user settings separately under the user's local application-data folder.
